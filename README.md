# 测绘与惯性导航学习笔记

这是我在研究生阶段学习惯性导航与组合导航时整理的笔记。仓库从数学基础入手，逐步记录概念理解、公式推导和实际应用；内容会随着学习持续更新。

## 参考书籍

本仓库主要参考牛小骥老师的《惯性导航与组合导航算法》。笔记以这本书为学习主线，结合我自己的理解整理；部分章节也会补充其他资料，并在相应笔记中注明。

## 学习位置与笔记目录

我按教材的章节顺序整理仓库，而不是按文件类型分类。下表的章节和页码依据手边的教材目录照片，方便翻书时定位；不同印次的页码可能有所差异。目前仓库的笔记集中在**第 2 章**和**第 4 章**，其他章节暂未收录。
